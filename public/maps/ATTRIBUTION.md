# Built-in map attribution

The built-in map library uses openly licensed cartography. The original SVG
maps remain in this folder as project art.

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Credit: **Cartography by Dyson Logos**.

The versions bundled here are the four-gray-level VTT derivatives prepared by
the [RaccoonVTT starter-art project](https://github.com/jwhitlow45/raccoon-vtt),
which resized some originals and reduced them to four gray levels. No content
changes were made.
